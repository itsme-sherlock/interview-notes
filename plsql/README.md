## Revision Strategy
- Read one concept note and rewrite one example from memory.
- Convert one cursor-based solution into set-based SQL to compare approach.
- Maintain a personal list of exception scenarios and how to handle them.

## Interview Preparation Order
1. Block anatomy and scope.
2. Data type anchoring and maintainability.
3. Control flow correctness and readability.
4. Cursor safety, locking, and error handling.
