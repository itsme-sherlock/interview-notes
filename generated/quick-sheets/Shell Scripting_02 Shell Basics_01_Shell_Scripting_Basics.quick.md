## Quick Sheet
- Start scripts with `#!/bin/bash`.
- Validate inputs early and return non-zero on failures.
- Quote variables: `"$var"`.
- Core control flow: `if`, `case`, `for`, `while`, `until`.
- File checks: `-f`, `-d`, `-r`, `-w`, `-x`, `-s`.
