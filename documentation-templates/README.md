# Documentation Restructuring Templates

**Transform reference docs into narrative-flow interview-ready guides.**

## What This Does

Converts:
- ❌ Textbook-style (alphabetical, dense)
- ➜ ✅ Narrative-flow (problem → concept → implementation → interview prep)

## Files

1. **TEMPLATE.md** — Copy-paste template (14-20 sections, all placeholders)
2. **QUICK_START.md** — Step-by-step instructions on how to use the template

## 2-Minute Quick Start

```
1. Copy TEMPLATE.md → Save as [YourTopic]_Guide.md
2. Replace [bracketed placeholders] with your content
3. Follow narrative flow (Why? → What? → How? → Examples → Best Practices → Q&A → Summary)
4. Done!
```

## Why Use This

✅ Interview-focused (keywords, Q&A, real scenarios)
✅ Readable (simple language first, technical depth second)
✅ Learnable (natural progression, analogies, transitions)
✅ Standardized (14-20 sections, consistent structure)

## Example Sections

```
Quick Sheet (5-7 bullets, simple language)
Table of Contents
Why Do We Need This? (problem statement)
What Is This? (simple definition + analogy)
How It Works (internal mechanisms)
Implementation (syntax, examples)
Best Practices (5-6 Avoid/Prefer pairs)
Common Mistakes (5-6 specific errors)
Interview Q&A (Conceptual, Comparison, Scenario)
Revision Summary (keywords, syntax)
```

## For Your Use

- **Copilot:** Reference TEMPLATE.md structure when generating docs
- **Manual:** Open TEMPLATE.md, fill in placeholders, reference QUICK_START.md if stuck
- **Both:** Quick structure ensures consistency either way

## Time Required

- **First doc:** 4-6 hours (learning curve)
- **Subsequent:** 2-3 hours each
- **Experienced:** 1-2 hours
