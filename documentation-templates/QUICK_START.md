# Quick Start: Using the Template

## 3-Step Process

### Step 1: Copy Template
```
Open TEMPLATE.md
→ Save as [YourTopic]_Guide.md
```

### Step 2: Replace Placeholders
```
[Topic] → Your topic name
[Concept name] → Simple definition
[Feature/Aspect 1-3] → Actual features
[Bracket items] → Your content
```

### Step 3: Fill Each Section
- **Quick Sheet:** 5-7 bullets, simple language
- **Why?:** Real problem it solves
- **What?:** Simple definition + analogy
- **Features:** Examples, syntax, parameters
- **Comparison:** Table showing alternatives
- **Best Practices:** 5-6 Avoid/Prefer pairs
- **Mistakes:** 5-6 specific errors with solutions
- **Interview Q&A:** Conceptual, Comparison, Scenario questions
- **Summary:** Keywords, syntax, 1-minute recap

---

## Key Principles

✅ **Simple language first** → Technical depth second
✅ **Real examples** → Must be runnable/realistic
✅ **Natural flow** → Each section leads to next
✅ **Interview ready** → Keywords bolded, Q&A included
✅ **Preserve all content** → Never lose information, only reorganize

## Verification Checklist (Before Done)

- [ ] Quick Sheet is understandable to someone new to topic
- [ ] Each section naturally leads to next (check transitions)
- [ ] All original content preserved (nothing lost)
- [ ] Interview Q&A has Conceptual, Comparison, and Scenario questions
- [ ] Best Practices show clear Avoid/Prefer examples
- [ ] Common Mistakes are specific (not generic)
- [ ] Keywords are bolded for memorization
- [ ] Code examples are realistic/runnable
- [ ] Revision Summary can be read in 1 minute

---

## Troubleshooting

**"Quick Sheet too technical?"**
→ Use everyday language, avoid jargon, add analogy

**"Sections feel empty?"**
→ Add more examples, or merge sections if not needed

**"Too much content?"**
→ Organize as: Basic examples → Advanced → Edge cases

**"Don't know what to put in [bracket]?"**
→ Read your source material, keep it simple, one concept per bullet

## For Copilot Users

When generating docs, reference this structure:
1. Start with Quick Sheet (5-7 bullets)
2. Include "Why Do We Need" section early
3. Add real examples (not pseudocode)
4. Include Best Practices and Common Mistakes
5. End with Interview Q&A and Summary

---

## Manual Creation Tips

1. **Start with Quick Sheet** → If you can't write simple 7 bullets, read more first
2. **Write transitions** → Each section should naturally lead to next
3. **Example-driven** → Every concept should have 2-3 real examples
4. **Simple first** → Define simply BEFORE technical depth
5. **Verify with checklist** → Run through checklist before finalizing
